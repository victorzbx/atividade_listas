## Exercícios Lista

1. Crie um progrma que receba do usuario entradas numéricas inteiras e armazene-as em uma lista. Percorra os itens e conte quantos são pares e quantos são ímpares.
2. Combine duas listas separadas em uma única lista unificada.
3. Crie um programa que receba palavras inseridas pelo usuário e armazene-as em uma lista de strings. Identifique qual string possui o maior número de caracteres.
